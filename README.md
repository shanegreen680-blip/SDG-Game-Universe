# SDG Game Universe

Official Windows beta downloads for SDG Game Universe.

**[Download the Windows beta — v0.16.196](https://github.com/shanegreen680-blip/SDG-Game-Universe/releases/tag/v0.16.196)**

This beta fixes saved-progress launch failures caused by an empty download-cache folder. It also includes an app-only reset that preserves games and saves, a wider Systems & Games window, more reliable settings, game-lock recovery, controller fixes and artwork-job cancellation improvements.

Earlier beta features remain included: scans focused on new games and missing artwork, per-game artwork searches, save-update notifications, guided controller setup, separate player profiles, Windows startup and background save sharing.

**Known beta issues:** work continues on some save-state bugs involving Epic, GOG and Amazon. PC saved-progress backups restore progress written by the game; they do not capture universal exact-moment save states. Compatible games, emulators and save formats are required. A main-PC server must receive the save before the source goes offline and remain available when another PC collects it.

Download installers and SHA-256 checksums from this repository's Releases page. Installation guidance and known limitations are included in each release.

Choose **Settings → Quit SDG** before upgrading. Install the same beta version on every linked PC used for save sharing.

The installer includes third-party source archives and licence notices. No Switch emulator, keys or firmware are supplied; users independently install and configure their preferred Switch emulator.
