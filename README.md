# SDG Game Universe

Official Windows beta downloads for SDG Game Universe.

**[Download the Windows beta — v0.16.201](https://github.com/shanegreen680-blip/SDG-Game-Universe/releases/tag/v0.16.201)**

**New in v0.16.201: Xbox controller input fix.** SDG could detect an Xbox controller but ignore its buttons in menus and guided setup. This update prevents unresponsive browser readings from hiding working Windows controller input. It also stops unmapped devices and unused stick/trigger inputs from leaving navigation blocked. The fix has been confirmed working on the owner's laptop.

The beta includes an optional **built-in Game Bar with CPU/GPU temperatures and FPS monitoring**. Enable **Settings → Show Game Bar**. Readings depend on supported hardware and sensor access; CPU temperatures require an existing PawnIO driver and Windows administrator approval for the Game Bar.

**Amazon Games cross-saves between PCs on the same local network are nearing completion.** The recent timestamp-only save mismatch, empty-cache download and temporary Windows publication-lock fixes remain included. Two Amazon games have transferred progress successfully in owner testing; broader game-by-game testing continues.

Steam and Epic SDG saves are **opt-in per game on each PC**. Amazon and emulator defaults remain unchanged. **Delete SDG saved copies** removes that game's SDG copies from this PC while preserving actual in-game progress and copies on other PCs; sharing stays paused until you enable SDG saves again.

This version retains the fresh-install extraction-path fix, app-only reset, wider system browser, settings and artwork improvements, guided setup, Windows startup and background sharing.

**Known beta limitations:** work continues on Epic, GOG and Amazon save compatibility. PC saved-progress backups restore progress written to supported local files, not universal exact-moment save states. A main-PC server must receive a save before its source goes offline and stay available for later downloads. Already-downloaded copies work offline.

Download the installer, SHA-256 checksum and testing guide from the release above. Choose **Settings → Quit SDG** before upgrading, then install the same version on every linked PC. No uninstall or reset is needed.

The installer includes third-party source archives and licence notices. No games, ROMs, Switch emulator, keys or firmware are supplied.
